# 根因结论：同一节奏「一会儿右手、一会儿左手」的完整因果

日期：2026-10-11
结论：**2026-10-06 那条 `if (cnt > 0) hand = -hand;` 是唯一原因。已恢复为参照的无条件换手。**

---

## 一、用户的问题（原话）

> 「同一个节奏 为什么要一会右手 一会左手」
> 「模拟用一个节奏会导致成一下以右撇子起手 然后 又变成左撇子 这并不合理」

问的是：**同一段节奏，为什么起手的手会变？**（不是问某个音被分给谁）

---

## 二、机制：怎么划分的

划片规则（`TimeSlicePartition`，与参照 `potato()` 逐片相同）：

1. 片长 = 半拍时间格 `60 / (bpm · 2^倍乘) / 2`
2. 每格把落进窗口的音**整片归一只手**（不切开）
3. **格与格之间翻手**
4. 格内 N 个音 → 取 `order` 表**第 N 行**（1-based）分手指 +
   `pressTimes` 表定按下时长 → **这就是「强弱拍」**
   （多音片才是强弱拍载体；单音片只有一档）

所以「手是谁的」= 前面翻过多少次手。

---

## 三、根因：手性锚在「数据」而不是「时间」

| | 代码 | hand 是什么的函数 |
|---|---|---|
| 参照 `ref_main.cpp:337` | `hand = -1 * hand;` （**每片都翻**） | **片序号奇偶 = 时间的函数** |
| 本移植 2026-10-06 `:539` | `if (cnt > 0) hand = -hand;` （**空片不翻**） | **装过音的片数 = 谱面数据的函数** |

一张谱有 **13% 空片**（主谱 289/2219；AWC 23.7%）。空片位置随谱面数据走，
于是「装过音的片数」这个计数被数据顶偏 → **手性相位整段漂移**
→ 同一段节奏在谱面不同位置由不同的手起手。

这就是「同一个节奏一会儿右一会儿左」的全部原因，
也正是用户 10-05 说的「**打三连音会污染手法**」——三连音簇把计数顶偏，污染其后全部。

```

```
