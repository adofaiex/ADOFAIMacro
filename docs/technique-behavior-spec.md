# 分片回退与懒松键：行为规格

## 0. 来源与边界

- 本文档描述分组策略 pieceFallback 的可观察行为，用于按行为重写。第 10 节记录懒松键的行为，供核对；本次不重写懒松键。
- 来源说明：作者在整理本文档前阅读过外部参考实现（memsys-lizi 的 ADOFAI_Macro 中 Python 版 technique.py 的 _build_pieces 及相关函数，该仓库未附许可证文件）。因此本文档不是严格的洁净室规格。
- 实现者只依据本文档与仓库内的类型定义工作，不打开外部参考仓库，不查找旧实现，不查看 scratch 目录。
- 本文档未覆盖的情形，由实现者按最保守且与本文档一致的方式处理，并在报告中写明。

## 1. 输入与输出

- 输入 notes：按时间不减排列的按点数组，每项有 time（秒）。
- 输入 attacks：与 notes 中非长按尾（非 HoldEnd）的按点一一对应、按 notes 顺序排列的列表，称为 attack。每个 attack 有：index（指向 notes 的下标）、profile（手法配置，决定左右手的键位布局）、cellLength（半拍长度，秒，正的有限数）。
- 输入 startRight：首个切片所在的手，true 表示右手。
- 输出：切片列表。每个切片有 start、end（attack 下标，左闭右开）、length、pressWindow（二者都等于该切片的宽度）、right（所在手）。
- 输出约束：
  1. 切片按顺序覆盖全部 attack，互不重叠，且不含空切片。
  2. 每个切片内的 attack 使用同一个 profile 对象（引用相等）。
  3. 切片内 attack 数不超过该手布局的键数（Capacity，最小按 1 计）。
  4. 所有切片的 length 与 pressWindow 都是正的有限数。
- attack 列表为空时，返回空列表。

## 2. 记号

- n：attack 数。
- t(i)：第 i 个 attack 对应按点的时间。
- c(i)：第 i 个 attack 的 cellLength。
- P(i)：第 i 个 attack 的 profile。
- run(i)：从 i 开始，与 P(i) 为同一对象的最长连续区间的上界（不含）。区间外的 attack 不计入当前切片。
- cap(i, h)：P(i) 在手 h 上的布局键数（Capacity），最小按 1 计。
- 层级 d：整数，0 到 7。
- 宽度 w(i, d)：c(i) 除以 2 的 d 次方，结果不小于 1e-9。2 的幂除法是精确的。
- 计数器 K[1..7]：整数，每项在 0 到 2^18 - 1 之间，初值均为 0。

## 3. 初始状态

- k = 0：下一个待分配的 attack 下标。
- T = 0：当前切片的起点时间。
- d = 0：层级。
- h = startRight：当前手。m = startRight：主手，之后不变。
- canMulti = false，pendingBack = false。
- S：已发出切片的记录栈，初值为空。每条记录包含：起点下标 s、attack 数 cnt、手 h、宽 w、起点时间 T、发出时的层级 d、发出前的计数器快照。
- steps = 0；步数上限 LIMIT = max(1000000, 256 × n)。

## 4. 主循环

每一轮按顺序执行。"回到第 1 步"表示开始下一轮。

1. steps 加 1。若 steps 大于 LIMIT，分组失败（见第 6 节）。
2. 令 i = k，W = w(i, d)，E = T + 0.995 × W。
3. cnt = 从 i 起、在 run(i) 之内、满足 t(j) < E 的连续 j 的个数。时间不减，满足条件的 j 构成一个前缀。
4. K_cap = cap(i, h)；off = (h 不等于 m)。
5. 若 cnt 大于 K_cap：
   a. 若 canMulti 为真且 off 为真，置 pendingBack = true。
   b. 若 d 小于 7：d 加 1，K[d] 置 0，回到第 1 步。
   c. 若 d 等于 7：cnt = K_cap。
6. 若 pendingBack 为真（此时 S 必非空）：
   a. pendingBack = false。
   b. 令 top 为 S 的栈顶。若 top.d 小于 7：弹出 top；h = m；T = top.T；k = top.s；K 取 top 的发出前快照的副本；d = min(top.d + 1, 7)；canMulti = false；回到第 1 步。
   c. 若 top.d 等于 7：不回退，继续第 7 步。
7. 发出切片：把 (s = k, cnt, h, w = W, T, d, K 的副本) 压入 S。此处记录的 d 是衰减前的层级。然后：
   a. 对 c 从 d 到 1，K[c] = (K[c] + 2^(16 − (d − c))) 对 2^18 取模。
   b. 当 d 大于 0 且 K[d] 等于 0 时，d 减 1。
8. k = k + cnt；T = T + W；h 取反；canMulti = true。若 k 小于 n 且 |t(k) - T| 小于 W × 0.01，则 T = t(k)。
9. 若 k 等于 n，结束；否则回到第 1 步。

## 5. 输出

按压入 S 的顺序遍历，跳过 cnt 为 0 的记录。每条记录输出一个切片：start = s，end = s + cnt，length = w，pressWindow = w，right = h。

## 6. 失败与回退

若步数超过上限，分组失败。调用方改用半拍分组（beatGrid）的结果，不得抛出异常。

## 7. 工作例

输入：三个按点，时间为 0.01、0.07、0.075 秒；每个 attack 的 cellLength 为 0.0625；左右手各只有 1 个键；startRight 为 true。

- 第一轮：k = 0，右手，W = 0.0625，cnt = 1，发出右手切片（宽 0.0625）。手切换为左手，T = 0.0625。
- 随后 k = 1、左手，cnt = 2 超过键数 1，且 canMulti 与 off 都为真，置 pendingBack，层级依次升到 1、2、3。
- 层级 3 时 W = 0.0078125，cnt = 1，可以容纳。第 6 步回退：弹出第一片，手回到右手，T 回到 0，k 回到 0，层级设为 1，计数器恢复为发出第一片之前的值。
- 此后：层级 1 发出右手切片（宽 0.03125，覆盖第 0 个按点）；左手的空切片不输出；右手在层级 1 溢出，升到 3，发出右手切片（宽 0.0078125，覆盖第 1 个按点）；左手发出切片（宽 0.0078125，覆盖第 2 个按点）。
- 输出：右手（宽 0.03125）、右手（宽 0.0078125）、左手（宽 0.0078125），共 3 片。

## 8. 性质

1. 切片覆盖全部 attack，按顺序，无空片，无跨 profile，且不超过键数。
2. 同一输入得到同一输出。
3. 300 个同时刻按点、单键手时，在有限步数内结束，并覆盖全部按点。
4. 空输入返回空列表。

## 9. 与外部参考的已知差异

- 外部参考在切片数超过按点数的 64 倍时停止，并丢弃之后的按点。本规格不采用此条件，改用第 3 节的步数上限，避免长空白段中的按点被丢弃。
- 外部参考在层级已达 7 时仍回退前一片。按源码推断，这会重复同一次溢出，可能不会结束。本规格在 d 等于 7 时不回退（第 4 节第 6 步 c），改为截断副手切片。
- 外部参考把长按尾也计入切片的键数。本规格的 attack 不含长按尾，与本仓库 TechniqueTimeline 的约定一致。
- 键数取布局的不同键数（Capacity），外部参考取键列表长度。键不重复时二者相同。
- 以上差异未经对照验证：当前环境没有 Python 运行时。

## 10. 懒松键（已实现，本次不重写，仅记录行为）

- 适用于非长按的按点。按下后保持按下，直到同一物理键的下一次按下。
- 松开时刻的计算：取 max(按下时刻 + 0.0003, 下一次按下 - 0.0002)，再不超过 下一次按下 - 0.000001，最后不早于按下时刻。
- 若该键之后不再被按下，则在最后一个按点时刻 + 0.015 秒松开。
- 长按不受影响。懒松键只改变松键时刻，不改变按点时刻、键的选择与切片。
- 三个时间参数取自外部参考的观察值。
